# Documentation

This index separates current guidance from historical work records. When code
and documentation disagree, use the following precedence:

1. accepted architecture decisions and current specifications;
2. current code and regression tests;
3. active or deferred requests;
4. archived requests and bootstrap records.

Archived material preserves rationale and provenance but is not an instruction
to reproduce an older implementation.
