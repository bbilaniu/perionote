# Architecture Decision Records

Architecture Decision Records (ADRs) document consequential Hygienenote
architecture decisions and the reasons behind them.

Files use `NNNN-short-decision-title.md`. ADRs normally contain Status, Context,
Decision, Rationale, Consequences, Alternatives Considered, and Follow-Up.
Statuses include **Proposed**, **Accepted**, **Superseded**, and **Deprecated**.
An accepted ADR should normally be superseded by a new ADR rather than silently
rewritten.
